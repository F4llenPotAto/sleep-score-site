# sleep-score-site

# Setting up the Sleep Score API development environment
* Install Python 3.13
* Make a virtual environment `.venv` directory
```
# On MacOS/Linux:
python3 -m venv .venv

# On Windows:
py -3 -m venv .venv
```
* Activate your created virtual environment
```
# On MacOS/Linux:
. .venv/bin/activate

# On Windows:
.venv\Scripts\activate
```

* Install dependencies into your virtal environment
```
pip install .
```
